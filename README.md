   # Avito Python Trainee Assignment: Matrix Spiral Traversal

   Тестовое задание Авито для Python-стажёра.
   [Ссылка на оригинальное задание](https://github.com/avito-tech/python-trainee-assignment)

   ## Что сделано
   - Асинхронное получение матрицы по URL (aiohttp).
   - Обход матрицы NxN против часовой стрелки от левого верхнего угла.
   - Базовая обработка сетевых ошибок.
   - Type hints и тесты.

   ## Как запустить
   1. Установить зависимости: `pip install aiohttp pytest`
   2. Запустить тесты: `pytest test_matrix.py`
